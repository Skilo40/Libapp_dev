# LibraryApp - Система обліку бібліотеки

## Виправлення помилок Docker Compose авторизації ✅

Система тепер повністю функціональна з виправленням наступних проблем:

### 1. Порт API (Порт 3000)
- **Проблема**: API контейнер не був доступний з хосту
- **Вирішення**: Додано `ports: - "3000:3000"` у docker-compose.yml

### 2. Автоматичне створення адміністратора
- **Проблема**: При першому запуску Docker база даних була порожня, адміністратор не створювався
- **Вирішення**: 
  - Створено `server/entrypoint.sh` скрипт
  - Обновлено `server/Dockerfile` для використання entrypoint
  - Тепер адміністратор автоматично створюється при першому запуску
